## 1. 文献及其可信范围

通称《数书九章》，本次引用的四库本题《数学九章》。二者在文献记录中分别保留。

| 编号 | 文献位置 | 本轮使用的内容 |
|---|---|---|
| [S1：序及附赞](https://www.shidianguji.com/zh/book/SK1553/chapter/1l9mvhphsi68j) | 四库本《数学九章序》，识典 SK1553 | 秦氏对大衍与《易》的直接说明 |
| [S2：蓍卦发微](https://www.shidianguji.com/book/GJ093/chapter/1l40c2hxsn38k) | 《数书九章十八卷》卷第一“大衍类”，识典 GJ093 | 总数术、求一术、五十／四十九与取爻说明 |
| [S3：续文与按语](https://www.shidianguji.com/zh/book/SK1553/chapter/1l9mvncgomp03) | 四库本卷一对应转录 | 三十三根算例及四库编者评论 |

秦氏序附赞说：“**聖有大衍，微寓於易。**”《蓍卦发微》直接以《易》的
“大衍之数五十，其用四十有九”为问题，要求求出术及数。因此这里有明确的作者论述与算例，
不只存在“大衍”二字的借名。该论述证明秦氏作过这种解释，不能据此倒推《易》原文已包含现代 CRT。

四库转录本的按语认为末尾以三归而取爻象有所附会。网页 S3 的标题
“按此條與數無取義可删”也是编者按语，不能读成秦氏自述。
这些批评针对易学解释，不是对模逆算法有效性的否定。

本轮只完成**两个数字转录的互校与算式复算**，没有完成影印原页逐字校勘，
也没有固定网页全文字节。S1—S3 的 URL 是来源定位，不是不可变版本保证。已记录的差异包括：

- S2 的“一与四求等乃得二”与 S3 的“二与四”不一致；复算使用后者。
- S3 将约定后的四数之积写成“一二三四”得十二；S2 对应作“一一三四”。
- S2 图前转录见“劣阴”，同页取象术文作“少阴”；本文采用术文用字。

上述校记保留在来源表中；没有据此修改外部转录或宣称确定其底本原字。

## 2. 总数术、求一术与取爻须分开

| 层次 | 本题中的作用 | 现代重述的边界 |
|---|---|---|
| 大衍总数术 | 整理诸数、形成衍母与衍数、用乘率合成余数 | 可与 CRT 的准备及合成比较；本轮不重建全部历史分支 |
| 大衍求一术 | 由奇数与定母求乘率 | 非平凡互质情形对应模逆；本轮未复现原文筹算递推 |
| 蓍卦解释 | 选择用数、将结果分为四象、六画成卦 | 属于另加的解释及取象规则，不能从逆元存在单独推出 |

以本题的数重算：

| 步骤 | 数值 | 性质 |
|---|---|---|
| 原数 | `(1, 2, 3, 4)` | 四个计数条件，并非两两互质 |
| 每位乘其余三数 | `(24, 12, 8, 6)` | 合计 **50** |
| 约定后定母 | `(1, 1, 3, 4)` | 乘积，即衍母 **12** |
| 衍母除以各定母 | `(12, 12, 4, 3)` | 衍数 |
| 乘率 | `(1, 1, 1, 3)` | 非平凡求逆为 `3 × 3 ≡ 1 (mod 4)` |
| 泛用数 | `(12, 12, 4, 9)` | 合计 **37** |
| 第二项增加衍母 12 | `(12, 24, 4, 9)` | 合计 **49** |

模 1 的位置不提供观测信息；表中相应的 1 是原算例的记法，不在本记录中作为通常的模逆见证。
37 与 49 相差一个衍母；第二项增 12 后，乘任意整数余数再求和也不改变模 12 的结果。
所以 **49 的选择包含额外的象数要求，不能说是求一算法唯一逼出的数**。

S3 随后取左手 33 根。按该例在整除时记足额余数的约定，四项为 `(1, 1, 3, 1)`，于是：

\[
12\times1+24\times1+4\times3+9\times1=57,
\qquad57\bmod12=9,\qquad9/3=3.
\]

秦文把象数 3 取为少阳。对正整数，本例余数可重述为 `((x - 1) % m) + 1`；
现代通常余数则是 `(0, 1, 0, 1)`。两种约定不能在文献转写时悄悄互换。
各原模数乘其对应权重都是 12 的倍数，保证这两种记法的模 12 结果一致。此处仅核验 33 这一取爻例，
没有裁定重建余数为零时的历史端点规则、完整揲蓍过程或成卦概率。

## 3. 严格可用的观察—合成结构

以下是现代数学重述。原四路中，模 1 没有信息，模 2 又由模 4 决定。
真正独立的重建可以写为

\[
x\equiv4r_3+9r_4\pmod{12},\qquad r_3=x\bmod3,\quad r_4=x\bmod4.
\]

| 选择元 | 模 3 的投影 | 模 4 的投影 |
|---|---|---|
| `e3 = 4` | 1 | 0 |
| `e4 = 9` | 0 | 1 |

在模 12 中还有 `e3² = e3`、`e4² = e4`、`e3·e4 = 0`、`e3 + e4 = 1`。
因此改变 `r3` 只影响对应的模 3 分量，改变 `r4` 只影响对应的模 4 分量。
四个原用数不能都被称为四个独立的 CRT 选择元。

复核附件独立枚举 `[0,12)` 中的余数纤维，并检查合成式覆盖全部十二个类。
增加模 1／模 2 两路后仍只有十二种可区分观察；观察条数增加而信息未增加。
而 9、21、33 的这几路观察完全相同：不限制整数范围，只能得到模周期的类，不能恢复唯一整数。

这给“有限观察者”一个具体实例：联合观察可以提高区分能力，区分结论仍依赖观察族与声明的范围。
它没有证明 adva 的任意观察算子都来自模数，也不能将交换的整数运算推广为历史次序可以交换。

## 5. 与太玄、来源去向及辅助位格的候选联系

本节属于**解释提议，尚未成立**。可以先建立以下区分：

| 层次 | 可候选对应的对象 | 进一步成立需要什么 |
|---|---|---|
| 来源到观察 | 一个记录按指定规则生成余数 | 指定来源、政策和可检查的投影见证 |
| 观察到合成 | 逆元产生的选择元及重建式 | 指定代数、可逆／相容条件与独立检查 |
| 辅助位格 | 某辅助项在特定通道中保留、屏蔽或协助的信息 | 明确主体、目标、通道；改变目标或通道后的对照实验 |
| 太玄情境与卦爻解释 | 有来源的文本及其情境标注 | 另行提出与复核解释，不能由整数编号推出 |

`4` 与 `9` 的辅助作用取决于选定的模 3／模 4 通道；它们不是脱离环境的固定主体类别。
这为“配伍能否读作主体的辅助位格”提供了一个可试验的数学模型，还没有赋予药物、五行或角色标签。
同样，把零投影叫作“阻碍”会引入额外语义；它目前只表示某一路看不到该贡献，不等于客体被破坏。

时、空、结构三侧即使能够交换信息，也不自动满足 CRT 的代数条件。必须先给出各自观察映射，
检验信息重叠、相容性与合成范围，再谈联合重建；信息交流本身不等于模数互质。
太玄的“来源／去向／时候”可以提供情境描述问题，但其编址和赞位没有在此获得数论等价性。

本文与现有[六爻实验](../changes/README.md)、[太玄实验](../taixuan/README.md)相接，
也沿用[禁止混淆记录](../../knowledge/conflations.json)中“可复核来源不等于语义标注为真”的区分。
这些解释没有加入监督标签、生成学习样本或改变文言运行时。

## 6. 可复算附件与下一步

从仓库根目录运行：

```sh
node experiments/qin-dayan/check.mjs
```

[check.mjs](check.mjs) 只用 Node 内置模块，复算上述具体算例，并在固定十二个剩余类上检查 CRT，
输出 JSON；不联网，不写文件，不运行历史筹算解释器。本轮 33 项检查全部通过，重放输出逐字节一致。
[evidence.json](evidence.json) 保存本轮输出，并绑定脚本和 [sources.json](sources.json) 的 SHA-256。
摘要绑定的是本地来源清单字节，不是外部网页全文或其历史真实性。

下一步应优先补影印页校勘和秦氏求一过程记录，再研究非互质相容条件的一般构造。
若继续位格实验，需要先固定主体、目标与观察通道，使失败和缺失观察也有明确的记录方式。
尚未核定的取爻端点保持未决，不以一次算例成功代替完整筮法验证。

本轮结果支持“大衍与易学存在实质联系”的直觉；关键收获是把文献、合成正确性、
来源忠实性和解释意义分开，使已有成果与未决部分都能继续被检验。
