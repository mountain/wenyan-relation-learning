# 互文关系：引用是可验证的文本关系

`node tools/intertext/extract.mjs [--write]` → `knowledge/intertext/citations.jsonl`

每条记录带四样：**宿主段落**（作品/节/段/源页/修订号）、**标记**（`《詩》曰` 等）、
**引文跨度**、以及**在被引作品自身文本中的回查结果**。「《詩》曰：X」与「X 见于詩經」
是两件不同的事，分开记。

## 检测器自己的假阳性（先测后建）

朴素正则 `(《|「)?(詩|書|易|禮|春秋|論語|孝經|爾雅)(》|」)?\s*(曰|云)` 报出 **12,501** 处。
抽样后发现四类污染，每一条都是真句子而不是引文：

| 命中 | 实为 |
|---|---|
| `遺羽書曰`、`遺章邯書曰`、`遺項王書曰` | **书信**（書=letter），非《尚書》 |
| `自為詩曰：「力拔山兮氣蓋世」` | **自己作诗**，非引《詩經》 |
| `范曄《後漢書》曰` | 命中「書》曰」，实为**後漢書** |
| `諸稱書、不書…書曰之類` | 春秋学的**术语** |

故严格规则：**只认带书名号的 `《詩》曰`**，得 **861** 处。裸形式（824 处：詩 486、書 176、
易 137、禮 25）是**宿主相对约定**，单独报告而不计入也不丢弃——左傳的「書曰」指春秋，
别处的「詩云」可能是作者在吟诗，单凭标记无法判定。

## 实测（861 处）

| 状态 | 数 |
|---|---|
| 在被引作品中找到 | **305** |
| 未找到 | 520 |
| 引文过短无法核验（<4 字） | 34 |
| 标记后无引文 | 2 |

**我没有把「60% 未命中」当成发现直接报**——先查了它。未命中偏高是**异体字**造成的：
仅加入 `於→于` 一项规范化，就多认出 **26** 条（33.0% → 36.1%）。其余含**真·逸詩逸書**，
例如論語引書「孝乎惟孝，友於兄弟」确不在传世尚書中（古文尚書·君陳佚文）。

这同时把 `knowledge/APERTURES.md` 的 **A7（异体字）** 从「未自动测量」变成了**有实测代价**：
单是一对 於/于 就藏了 26 条引用。

## 不声称

- 命中不等于引用准确，也不等于宿主所指就是该书（古典引用常为转述）。
- 未命中不等于不存在：本站文本不全，异体字也未穷尽（A7 仍开）。
- 不声称一部影响了另一部。这是一组**测得的文本关系**，不是影响史。
