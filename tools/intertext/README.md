# 互文关系：引用是可验证的文本关系

`node tools/intertext/extract.mjs [--write]` → `knowledge/intertext/citations.jsonl`

每条记录带四样：**宿主段落**（作品/节/段/源页/修订号）、**标记**（`《詩》曰` 等）、
**引文跨度**、以及**在被引作品自身文本中的回查结果**。「《詩》曰：X」与「X 见于詩經」
是两件不同的事，分开记。

## 检测器自己的假阳性（先测后建）

朴素正则 `(《|「)?(詩|書|易|禮|春秋|論語|孝經|爾雅)(》|」)?\s*(曰|云)` 报出 **12,501** 处。
抽样后发现四类污染，每一条都是真句子而不是引文：

| 命中 | 实为 |
|---|---|
| `遺羽書曰`、`遺章邯書曰`、`遺項王書曰` | **书信**（書=letter），非《尚書》 |
| `自為詩曰：「力拔山兮氣蓋世」` | **自己作诗**，非引《詩經》 |
| `范曄《後漢書》曰` | 命中「書》曰」，实为**後漢書** |
| `諸稱書、不書…書曰之類` | 春秋学的**术语** |

故严格规则：**只认带书名号的 `《詩》曰`**，得 **861** 处。裸形式（824 处：詩 486、書 176、
易 137、禮 25）是**宿主相对约定**，单独报告而不计入也不丢弃——左傳的「書曰」指春秋，
别处的「詩云」可能是作者在吟诗，单凭标记无法判定。

## 实测（861 处）

| 状态 | 数 |
|---|---|
| 在被引作品中找到 | **305** |
| 未找到 | 520 |
| 引文过短无法核验（<4 字） | 34 |
| 标记后无引文 | 2 |

**我没有把「60% 未命中」当成发现直接报**——先查了它。未命中偏高是**异体字**造成的：
仅加入 `於→于` 一项规范化，就多认出 **26** 条（33.0% → 36.1%）。其余含**真·逸詩逸書**，
例如論語引書「孝乎惟孝，友於兄弟」确不在传世尚書中（古文尚書·君陳佚文）。

这同时把 `knowledge/APERTURES.md` 的 **A7（异体字）** 从「未自动测量」变成了**有实测代价**：
单是一对 於/于 就藏了 26 条引用。

## 不声称

- 命中不等于引用准确，也不等于宿主所指就是该书（古典引用常为转述）。
- 未命中不等于不存在：本站文本不全，异体字也未穷尽（A7 仍开）。
- 不声称一部影响了另一部。这是一组**测得的文本关系**，不是影响史。

## 异体字表：数据，不是散落的 replace

`knowledge/intertext/variants.json`。**入库规则**：必须是**同词的书写变体**（orthographic），
绝不收**通假**（不同词之间的音借）；且**实测边际收益须大于零**——没有收益的条目买不到东西，
却增加"匹到并非同一段文本"的风险。

| 收 | 依据 | 实测收益 |
|---|---|---|
| 於→于 | 同一介词，文本间自由互换（詩經作「刑于寡妻」，孟子引作「刑於寡妻」） | **+18** |
| 无→無 | 无是無的古体，易全篇用无（无咎、无妄），詩經/尚書用無 | +1 |

**13 对实测收益为 0，已记入 `rejected`**——那个零是结果，不是遗漏（惟/维、惟/唯、唯/维、
与/與、尔/爾、说/悅、女/汝、弟/悌、反/返、见/現、竟/境、孰/熟、塗/途）。
另有一对 **知→智 收益为 1 但拒绝**：它是**通假**而非异体，为 1 条收益让「知」处处匹到「智」
不值。

## 宿主相对约定：per host 声明，并接受测量

`knowledge/intertext/conventions.json`。824 处裸标记不能计入也不能丢弃：某些宿主里裸名
**就是**引用该书的方式，另一些里则是作者在吟诗或写信。判定依赖**宿主**，所以逐宿主声明。

已声明 **左傳的「書曰」= 春秋經**，并用测量验证：14 处带引号者 **9 处（64%）** 命中春秋經正文。
未命中的样本是 `寔來`、`天王出居于鄭`、`鄭公子歸生弒其君夷。`——**典型的春秋纪年体**，
说明它们更像匹配器的漏失（短片段、跨段）而非反例。故记为**支持但未确立**（64% 是下界）。

未声明：`文選` 的「詩云」（选本里的裸「詩」可能正在被引也可能正在被作）、以及**其他宿主的「書曰」**
（那里 書 常指**书信**——朴素检测器报出 12,501 处而非 861 处，主因就是这个）。
