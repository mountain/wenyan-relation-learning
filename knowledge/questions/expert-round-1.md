| 类别 | 可否据此改写文本 | 定义 |
|---|---|---|
| 异体字 | 可 | 同一个字的两种（或多种）写法。 |
| 异写 | 可 | 音义相同而写法不同，常作为异体的实际使用形态（罗小虎：惟常作唯的异体/异写）。 |
| 古今字 | 可 | 同一个字的前后写法，一个古字一个稍后的字（罗小虎：雍→雝，一个古字一个稍微现代）。 |
| 通假字 | 不可 | 本字与借字音同或音近而借用，属于不同的词（罗小虎：普→溥「也不是严格异体字，算通假字或是看具体情况」）。 |
| 异文 | 不可 | 不同版本、不同征引之间的文字差异（罗小虎：异体、异文、通假这么说比较准确，但其实要看具体文章）。 |
| 不同字 | 不可 | 本来就是两个不同的字，各有各的音义（罗小虎：毋表示禁止、不要，無表示没有；協→洽不算异体字就是两个字）。 |
| 未判定 | 不可 | 尚未请教，或尚未落实到具体篇目。可以记录，不得计入书写变体收益。 |
| 通用字 | 可 | 两字长期通用、音义相近，古籍与征引中自由互换（本项目判定：於/于）。 |

总原则（您的话）：**异体、异文、通假等这么说比较准确，但其实要看具体文章**。

## 三、口径问题（4 条）

1. **年代范围怎么记**：您说 緡/緜「要看年代，在先秦或早期应该是两个字」。我们想记成「对 + 适用范围」，范围由谁定？(a) 我们按先秦／汉以后粗分并标出处 (b) 您给一份清单 (c) 只记「先秦为两字」这一条。
2. **於/于**：本项目暂归「通用字」，18 条引用依赖它。若您判为两个字或异文，这 18 条要撤——撤得掉，所以请您直接判，不要客气。
3. **版本**：您此前说「先依照公认的好的版本来推进，保留后来修改的口子」。现在每部书记的是维基文库页面 + 页面版本号（可回溯到具体 revision）。能否给一份公认善本清单，或至少指出底本明显不对的书？
4. **同名篇目**：詩經 揚之水 ×3、羔裘 ×3 等，同一部书里出现同名篇目（怀疑是同题异篇）。要不要在标题上加首句区分？加会改标题（记录会跟着变），所以先问。

## 四、您的判定之后会发生什么

- 每对必须声明类别，**代码强制**：没类别或类别不可计的，`tools/intertext/extract.mjs` 直接报错，不会悄悄用来改写文本。
- **未判定 = 不计收益**，也不会被当成异体字用。
- 判定带**范围**（篇目／时代），因为您说类别随文章与年代而变，我们不把它当全局常量。
- 引用的匹配数会**重新测量**，涨跌都照实报——上次 +44 → +12 就是照实报的。
